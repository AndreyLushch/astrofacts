# astrofacts

Расчётный слой астрологических данных: HTTP-сервис, который по дате и таймзоне отдаёт
астрономические факты суток — события с моментами времени, а не снимок неба на полночь.

Состояние: реализован первый шаг расчёта — сканирование суток (`astrofacts.sky.scan_day`,
результат — `DaySky`). Проекция на знаки, схема ответа и HTTP-сервис — в работе.

## Лицензия

AGPL-3.0, см. `LICENSE`. Сервис использует Swiss Ephemeris (Astrodienst AG) на условиях AGPL;
см. `NOTICE`. Потребители обращаются к сервису только по HTTP и не импортируют его код.

## Разработка

    python3 -m venv .venv
    .venv/bin/pip install --find-links ~/wheels -e '.[test]'
    .venv/bin/python tools/fetch_reference_kernel.py   # ядро JPL для сверочных тестов, один раз
    .venv/bin/python -m pytest

Тесты работают без сети. Без ядра JPL сверочные тесты пропускаются с сообщением.

Сервис в сеть не ходит: эфемериды (`src/astrofacts/data/ephe/*.se1`) лежат в репозитории
и попадают в дистрибутив.

## Конфигурация

`src/astrofacts/data/default.toml`: тела, аспекты, орбы, порог скорости, окно станций,
окно опережения. Другой файл подключается переменной `ASTROFACTS_CONFIG`.

## Вспомогательные скрипты

- `tools/precision_stats.py` — сколько событий отдаётся с временем и сколько датой;
- `tools/voc_dates.py` — интервалы Луны без курса по двум конвенциям, для ручной сверки.
