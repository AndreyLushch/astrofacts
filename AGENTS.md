# AGENTS.md

Правила проекта для LLM-инструментов (Cursor и других). Полная версия — в `CLAUDE.md`,
она обязательна к прочтению перед работой; при расхождении действует `CLAUDE.md`.

## Коротко
- astrofacts — отдельный публичный сервис под AGPL-3.0. Потребители общаются с ним только
  по HTTP + JSON: ничего отсюда не импортируют, клиентской библиотеки для них нет и создавать
  её нельзя.
- Файлы эфемерид `.se1` в репозиторий не кладутся: их загружает `tools/fetch_ephemeris.py`.
- Сервис в рантайме в сеть не ходит.
- Это рабочий каталог разработки. Сервис запущен не отсюда, а из `~/deploy/astrofacts-dev`.
- Цикл: правка → `scripts/dev.sh test` → коммит → `scripts/dev.sh deploy` (сам прогоняет полный
  набор тестов без пропусков) → `scripts/dev.sh check` / `day`.
- Выкатывается коммит, а не файлы рабочего каталога. Описание: `deploy/README.md`.
- Прод сам выкатывает `main` раз в 5 минут.
- Орбы, пороги и конвенции — только в `src/astrofacts/data/default.toml`, не в коде.
- В ответе сервиса нет абсолютных долгот. Изменение схемы, ломающее потребителя, увеличивает
  `SCHEMA_VERSION`; описание для потребителей — `docs/CONSUMERS.md`.

## Без явного запроса нельзя
- `git push` (push в `main` выкатывает прод) и любые действия с продом;
- трогать `/opt`, `/etc` и другие проекты в `~/projects`;
- править файлы в `~/deploy/astrofacts-dev/releases` и `current`;
- пополнять `tests/manual/astroseek.toml`: эталон вносит человек после ручной сверки.
