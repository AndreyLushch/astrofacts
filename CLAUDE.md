# CLAUDE.md

## Назначение
**astrofacts** — HTTP-сервис, считающий астрономические факты суток для астрологических
прогнозов. Потребители — другие сервисы на той же машине. Этот каталог — рабочий каталог разработки
на dev-сервере; прод — отдельный сервер (`/opt/astrofacts`), доступа к нему отсюда нет.

## Граница, которую нельзя нарушать
Сервис использует Swiss Ephemeris на условиях AGPL, потребители закрыты. Поэтому:
- репозиторий публичный, лицензия AGPL-3.0;
- потребители не импортируют ни строки отсюда; контракт — только HTTP + JSON;
- клиентскую библиотеку-обёртку для потребителей не создавать;
- файлы эфемерид `.se1` в репозиторий и дистрибутив **не класть** (они в `.gitignore`):
  их загружает `tools/fetch_ephemeris.py` при развёртывании;
- сервис в рантайме в сеть не ходит и ничего не скачивает.

## Пути
- Рабочий каталог (git): `~/projects/astrofacts`
- Dev-инстанс: `~/deploy/astrofacts-dev` (`releases/`, `current`, `ephe/`, `venvs/`)
- Код: `src/astrofacts/`; схема ответа — `schema.py`; конфигурация расчёта — `data/default.toml`
- Выкатка: `scripts/deploy.sh`, `scripts/dev.sh`, описание — `deploy/README.md`

## Устройство
- `ephemeris.py` — единственный модуль, импортирующий `swisseph`. Состояние библиотеки своё
  у каждого потока: путь к файлам задаётся в каждом потоке.
- Шаг 1: `sky.scan_day` → `DaySky` (траектории и события, точные долготы — только здесь).
- Шаг 2: `assemble.build_day_facts` → `DayFacts` через системы отсчёта (`frames/`).
- В ответе нет абсолютных долгот. Орбы, пороги и конвенции — только в конфигурации.
- Изменение схемы, ломающее разбор у потребителя, увеличивает `SCHEMA_VERSION`.

## Рабочий цикл
1. Правка → `scripts/dev.sh test` (быстрая проверка черновика).
2. Коммит.
3. `scripts/dev.sh deploy` — полный набор тестов для коммита без пропусков (`test-full`), затем
   выкатка на dev; без пройденного полного набора релиз не собирается.
   Проверка: `scripts/dev.sh check`, `day`.
4. Push в `main` — **только по запросу**: прод сам выкатывает `main` в течение ~5 минут.

Сверочные тесты требуют astropy и ядра JPL (`tools/fetch_reference_kernel.py`); эталон из
`tests/manual/astroseek.toml` пополняет только человек после ручной сверки.

## Чего не делать без явного запроса
- `git push` и любые действия с продом;
- трогать `/opt`, `/etc` и другие проекты в `~/projects`;
- править файлы внутри `~/deploy/astrofacts-dev/releases` и `current`.
